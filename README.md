# BeatInsight

BeatInsight — разрабатываемый мод Beat Saber для анализа выбранной карты.
Он помогает оценить нагрузку на каждую руку, увидеть распределение сложности
по песне и найти участки, на которых предыдущие попытки закончились поражением.

## Возможности

- Среднее, максимальное и медианное число свингов в секунду для каждой руки.
- Направления первых кубов.
- Подсчёт приседаний и предупреждения о них.
- Цветовая полоса нагрузки на протяжении песни.
- Отметки мест смерти: красные кресты для собственных записей и жёлтые для
  импортированной истории.
- Настройки отображаемых показателей, полосы и источников отметок смерти.
- Выборочный анализ: скрытые показатели не рассчитываются.
- Независимый вывод доступных показателей: ошибка анализа нот не скрывает
  проверенный счётчик приседаний; недоступные значения отображаются прочерками.
- Возможность отключить запись смертей с сохранением существующей истории.

Если показатель недоступен, его подсказка объясняет причину на английском:
например, движение игрока, поворот объектов или неподдержанная анимация.
Отсутствующие данные карты и ошибки анализа обозначаются отдельно.

Медиана описывает типичную активную секунду: пустые окна исключаются, каждая рука
рассчитывается отдельно. Тренировки не включаются в историю смертей.

Настройки доступны во вкладке **BeatInsight** на панели настроек перед запуском песни.
Предупреждение о приседании — надпись `DUCK` или два красных круга.
Можно отключить сигнал и настроить упреждение от 0,5 до 5 секунд.

Подсказки истории доступны над верхним краем полосы даже без крестов:
импортированная история слева, собственная справа. Если включён один источник,
его область занимает всю ширину. Подсказки объясняют недоступность истории,
скрытые позиции и точность записей. При выключенной плотности остаётся
нейтральная дорожка истории.

## Состояние проекта

Целевая версия игры — **Beat Saber 1.40.8**. Сейчас доступны автономный анализ карт
форматов v2/v3/v4, расчёт показателей и работа с файлами истории. Результаты можно
получить в JSON через инструмент командной строки.

Подготовлена экспериментальная сборка с показателями, первыми кубами и графиком
истории в меню, а также автоматической записью поражений. Для карт, требующих
только Chroma, доступны расчёты показателей по игровым объектам. Световые эффекты
не воспроизводятся; первые кубы обозначают руки стандартными цветами.
Для Mapping Extensions в меню доступны расширенные координаты, углы нот,
повёрнутые кубы с точкой и расчёт приседаний по дробной геометрии стен.
Предупреждения для расширенных стен подготавливаются до старта песни по загруженным
игровым препятствиям. Фактический показ в игре ещё требует проверки.
Для Noodle Extensions доступен ограниченный режим меню: обычные игровые объекты,
статические координаты нот и бомб v2/v3 и голов/хвостов дуг v2/v3.
Для v2 поддержан пользовательский угол первой ноты, включая точку.
Для обычных нот v3 поддержаны анимации появления с проверенными easing, полностью
возвращающие ноту в исходную позицию до её номинального времени. Они сохраняют
номинальные показатели свингов; при неизвестном физическом наклоне куб получает
пунктирный фон. Нулевые смещения обычных объектов v2/v3 также поддержаны.
Для обычных несвязанных настоящих нот v3 поддержано также локальное вращение
появления, возвращающееся в ноль строго до номинального времени ноты.
Физический наклон первой ноты при таком вращении остаётся неизвестным.
Для обычных настоящих бомб v3 поддержано появление со смещением, полностью
возвращающимся в исходную позицию до номинального времени.
Для настоящих бомб v3 флаги `disableNoteGravity` и `disableNoteLook`
поддержаны для текущих номинальных показателей. Физическая высота бомбы
при этом может меняться; точная траектория не вычисляется.
Для настоящих бомб v3 поддержаны также треки с нейтральными значениями
на номинальном времени: нулевым смещением и единичным path-масштабом.
Для положения цветных нот v2/v3 можно использовать именованные определения
кривых с теми же ограничениями. Поддержаны Linear и варианты In/Out/InOut
для Quad, Cubic, Quart, Quint, Sine, Circ, Expo и Bounce.
Для обычных несвязанных настоящих нот v2/v3 флаги `disableNoteGravity` и
`disableNoteLook` сохраняют номинальные показатели; физический наклон
первых кубов при этих флагах считается неизвестным.
Для настоящих цветных нот и обычных дуг v3 допускается явный нулевой `worldRotation`
в режимах Standard, Lawless, OneSaber и NoArrows без событий поворота сцены.
Ненулевые мировые повороты пока не поддержаны.
Для треков v3 поддержана прозрачность через `AssignPathAnimation`.
Независимые события других треков не блокируют запрошенные показатели,
если в карте нет окружения и родительских связей, а типы событий и их
данные распознаны. Динамика запрошенного трека проверяется отдельно.
Кривые прозрачности объектов поддерживают те же 25 easing в кадрах
`dissolve` и `dissolveArrow`; прозрачность не исключает ноты из показателей.
Для обычных несвязанных настоящих нот v3 поддержаны path-кривые треков:
смещения должны вернуться в ноль, а масштаб — в единицу строго до
номинального времени ноты. Для `AnimateTrack offsetPosition` с монотонным easing при постоянном BPM поддержаны
ноты после завершения смещения в ноль; повторы, пересечения событий
и ноты во время ненулевого смещения пока ограничивают анализ. При path-геометрии наклон первой ноты считается неизвестным.
Именованные статические треки поддержаны в картах без custom events и изменений окружения.
Есть ограниченная поддержка обычных цепочек v3
с однозначной настоящей нотой-головой, рядами настоящих нот и совпадением
головы с головой или хвостом обычной дуги. Поддержана одиночная настоящая нота
точно на хвосте цепочки, включая другой цвет, статические координаты и совпадение
с головой следующей цепочки либо концами обычных дуг.
Цепочка с `sliceCount: 1` поддержана при наличии настоящей головы:
дополнительных слайсов нет, учитывается один номинальный свинг.
При нулевой длительности её хвост может совпадать с собственной головой
или точной настоящей нотой другой руки.
Цепочки с настоящей головой и одинаковым временем головы и хвоста
поддержаны как один номинальный свинг, если хвост не совпадает с другими
объектами. Отрицательные интервалы не поддержаны.
Изолированная цепочка без головы, включая статические координаты, считается
одним свингом на времени первого слайса; первая нота отображается точкой
с неизвестным наклоном. Пересечения таких цепочек пока не поддержаны.
Для счётчика приседаний поддержаны координаты, ширина и высота стен v2/v3,
а также укороченная физическая длина при известной постоянной скорости.
Горизонтальная координата стены может выходить за обычную сетку.
Для расширенного вертикального слоя нужны явные координаты Noodle и высота.
Поддержан локальный наклон
стен в плоскости экрана при явно заданной высоте. Удлинённые стены, остальные
повороты ещё не поддержаны. Стены v3 с `uninteractable: true`
исключаются из физического расчёта и предупреждений, включая декоративные
анимированные стены; для обычных стен ограничения геометрии сохраняются. В меню доступно XY-появление
стен v3, если смещение завершается до номинального контакта при выбранных
настройках прыжка и обычной скорости песни. Предупреждения для
этого случая готовятся до музыки при стандартном загруженном движении
без индивидуальных overrides; фактический показ ещё требует проверки. Непроверенные свойства
возвращают явный отказ. Поддержанные fake-ноты исключаются из свингов, графика
и индексов истории. Fake-стены не создают приседаний и предупреждений.
Статические координаты fake-нот поддержаны; fake-дуги/цепочки ещё не обработаны.
Fake-ноты рядом с настоящей головой цепочки участвуют в подготовке наклона ряда,
но исключаются из показателей и выбора первой ноты.
Если наклон головы-точки зависит от порядка обработки ряда, куб сохраняет точку
и пунктирный фон; остальные показатели остаются доступны.
На картах с переопределёнными координатами, анимацией появления, флагами движения, неинтерактивными стенами или цепочками Noodle импортированные
кресты скрыты,
поскольку соответствие старых индексов не проверено. Свои записи сохраняют время.
Для поддержанных статических стен предупреждения подготавливаются до песни
с учётом режима рук. Непроверенные динамические варианты пропускаются. Фактический показ
нового расписания в игре пока не подтверждён.
У настоящих бомб v2 поддержан пользовательский угол `_cutDirection`;
бомбы сохраняют свой тип и не учитываются как свинги.
Для обычных настоящих цветных нот v3, включая головы и хвосты поддержанных
дуг на картах без цепочек, поддержан канонический `size: [1,1,1]`.
Допускаются проверенные лишние legacy-поля `_position`, единичный `_scale`
и `_cutDirection` внутри `customData`; они не подменяют поля v3.
Изменённый `scale` остаётся неподдержанным.
Сочетание Noodle с Mapping Extensions и другие обязательные расширения пока
не поддерживаются.

Если неподдержанные данные относятся только к стенам, меню сохраняет проверенные
показатели нот и график. Для недоступного числа приседаний отображается прочерк.
Непроверенные изменения нот или движения игрока по-прежнему ограничивают анализ.
На Noodle-картах v2/v3 график номинальной плотности объектов доступен
независимо от геометрии в режимах Standard, Lawless, OneSaber и NoArrows.
Для v3 учитываются обычные дуги, связанные с ними бомбы и цепочки с проверенной
головой либо изолированные цепочки без головы. Цепочка учитывается как одна
группа. Дуги v2 требуют проверенной геометрии. Fake-объекты не учитываются.
Такой график не подтверждает свинги или положение первых нот:
неподдержанные значения сохраняют прочерки.

## Установка

Требуются **Beat Saber 1.40.8**, **BSIPA 4.x от 4.3.0** и
**BeatSaberMarkupLanguage 1.x от 1.12.5**.

Закройте игру и распакуйте `BeatInsight-1.40.8.zip` в корень нужного экземпляра
Beat Saber, сохраняя каталоги `Plugins` и `Libs`. Затем запустите игру.
Архив содержит только четыре собственные DLL; зависимости устанавливаются отдельно.

Настройки сохраняются в `UserData/BeatInsight.json`, собственная история смертей —
в `UserData/BeatInsight.Deaths.json`. Обновление DLL не требует удаления этих файлов.

Для игровой диагностики включено событийное логирование (`DiagnosticLogging`
в файле настроек). Записи `BI-DIAG` попадают в обычный игровой журнал в `Logs`.
Отключение: `DiagnosticLogging: false`. Описание данных —
[docs/runtime-diagnostics.md](docs/runtime-diagnostics.md).

При No Fail красный крест сохраняется после доигранной карты, если энергия
обнулилась: позиция соответствует первому обнулению. Выход, рестарт, тренировка
и перемотка такую запись не создают.
