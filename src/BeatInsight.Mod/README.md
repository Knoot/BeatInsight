# Игровой слой BeatInsight

Экспериментальный BSIPA-плагин Beat Saber 1.40.8: захват поражений стандартного
одиночного прохождения, запись собственной истории и анализ выбранной карты
для будущего UI. Проект собирается в
`netstandard2.1`; установленные игровые зависимости разрешаются самой игрой.
Сборка и проверка метаданных выполнены, запуск в игре ещё не проверен.

Плагин использует BSIPA и Harmony без новых зависимостей от других модов.
Main/DataModels/GameplayCore проверяются по исследованным хешам до установки
хуков. Сборка автоматически в игру не копируется.

Подключены начало попытки, levelFailedEvent, завершение и очистка подписок.
Restart повторно использует scene setup, поэтому новая попытка создаётся при
старте нового игрового менеджера. Время берётся из songTime без пересчёта скорости;
fallback из endSongTime явно обозначается как оценка. Тренировки, успешные
прохождения и добровольные выходы/перезапуски без поражения записей не создают.
Захваченное поражение сохраняется и при последующем выходе/перезапуске.
Повторные callbacks не должны создавать вторую запись той же попытки.

Запись в `BeatInsight.Deaths.json` идёт последовательно в фоне; путь определяется
через IPA UserDataPath и выводится в лог. SongPlayData.json этот плагин не открывает.
На отключении подписки снимаются, ожидается завершение записи до пяти секунд.
Ошибки IO логируются; повтор записи после ошибки и сохранение при аварийном
завершении процесса пока не гарантируются.

Реализованы хуки меню и конвейер данных выбранной файловой карты: отмена устаревших
запросов, показатели/график и чтение маркеров истории. API для UI — MenuAnalysis.Current
и Changed. Встроенные источники без FileSystemBeatmapLevelData пока Unsupported.
Реализованы показатели в согласованном порядке, число приседаний, цветные кубы
со стрелкой/точкой и наклоном, график и кресты истории. Сборка проверена автономно;
реальные размещение и события в Unity ещё не проверены. Предупреждения WallAlert
во время прохождения ещё не перенесены.
Не менять исходный WallAlert и не считать подсчёт приседаний заменой предупреждений.

Сборка: `pwsh -NoProfile -File tools/Build-Mod.ps1` из корня проекта.
Пакет содержит четыре собственные DLL: BeatInsight.dll, BeatInsight.Core.dll,
BeatInsight.Formats.dll и BeatInsight.WallAlert.dll. Используется установленный BSML.
Подробности: [menu-rendering.md](../../docs/menu-rendering.md), [game-layer.md](../../docs/game-layer.md),
[death-history.md](../../docs/death-history.md).
Конвейер меню и проверки без VR: [menu-analysis.md](../../docs/menu-analysis.md),
`pwsh -NoProfile -File tools/Test-MenuAnalysis.ps1`.
